# History

Everything in this directory is historical. It is kept for context, not as a runbook.

- `HANDOFF-2026-05.md` — old project handoff, superseded by the root README.
- `plans/` — 50 implementation plans from May–July 2026.
- `specs/` — 10 design specs from the same period.
- `reports/` — old status reports, including the pre-existing improvement report.

Each file starts with `status: historical`. Do not copy commands or architecture
claims from here into current docs without re-checking the code.
